Phase 2 Evaluation Run once across all measures
STAGE 5
Data Preprocessing
CPU + OpenRouter (Opus 4.6) + MiniLM
5.1 Collect both-KEEP rows from all measures, dedupe by user_input, merge measures into list. Apply global chitchat_keep=false veto.
5.2 Classify single-turn vs multi-turn via Opus 4.6.
5.3 Semantic dedup of single-turn (cosine ≥ 0.85). Tag with synthetic:false, language:"English".
→ data/final.jsonl
